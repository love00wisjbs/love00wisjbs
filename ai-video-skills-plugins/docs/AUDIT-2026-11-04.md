## Runway 收录边界

逐份阅读并保留上游 7 个 skills，不改写指令。保留 LICENSE，固定上游提交，记录每文件 Git blob SHA 与 SHA-256。通过仅表示适合存档和按需安装，不能证明模型 API 或远程服务无漏洞。

- runway-dev：基础 SDK、安全和计费边界。
- runway-dev-setup：账号、项目和 OAuth 引导。
- runway-dev-models：直接模型接口，包括视频。
- runway-dev-model-routers：模型路由；可修改账号资源，按需安装。
- runway-dev-recipes：多步生成方案。
- runway-dev-workflows：调用已发布工作流。
- runway-dev-characters：实时互动角色，属于附加能力，不是文本生成数字人口播视频。

## 插件与 skills 的区别

ChatGPT 插件目录查到 Runway 已安装，HeyGen / Higgsfield 未安装。已读取 Runway 当前 ChatGPT 操作审批设置：继承默认的“允许低风险操作”；该设置不是 OAuth scope，也不是远程后端源码审计结果。

本目录的 Runway Dev 开源项目与 ChatGPT 的 Runway 媒体生成连接器不是同一个产品包。后者能直接生成媒体，不能把其已安装状态当作 Dev MCP 已完成 OAuth。

远程 MCP 服务不能被复制进 GitHub；仓库仅能保存客户端配置示例和审查记录。没有安装或连接新的插件，没有复制闭源服务。

## 免费额度

所有候选均未验证 API 免费额度。Runway 网页 125 一次性积分不构成 Dev API 免费额度承诺；HeyGen MCP 配置声称消耗现有套餐积分，也不保证免费套餐允许该调用。运行前分别检查账户、可用模型和当前报价。
