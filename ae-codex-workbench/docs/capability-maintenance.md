# 可复用能力维护

这份仓库保存可复用工具、参考和验收记录；它不会修改模型参数，也不自动给不可见会话或其他设备安装能力。

用户已授权在大方向下自主判断具体改进项。下一轮先检查已有进度和实际缺口，自行完成必要研究、实现、测试和 GitHub 保存；需要新账号登录、设备安装或不明确的不可逆操作时，先说明。

## 已补齐：只读 skill 盘点与引用检查

以前盘点和链接检查依赖零散临时命令，Windows 接续时难以直接复用。现在提供 `tools/audit-skills.cjs`，使用 Node 内置模块、不需要 npm install。源文件和测试均为本包原创，按本包 MIT 许可。

在本仓库 `ae-codex-workbench` 目录，Windows PowerShell 或云端终端使用同一命令：

```text
node tools/audit-skills.cjs .
node --test --test-isolation=none
```

也可以将 `.` 替换为你明确选择的其他技能资料目录；包含空格的路径用双引号括住。不需要把工具部署到 agent 技能目录。

结果是 JSON：

- `schemaVersion`：当前为1，供以后脚本识别格式。
- `root`：实际扫描的绝对路径；报告保留本机路径，不作为跨设备配置。
- `skills`：SKILL.md 相对路径、可识别的name、空白分隔词数、UTF-8字节数和SHA256。
- `issues`：severity、code、相对path、message；没有问题时为空数组。

|结果码|含义|
|---|---|
|0|未发现 error；仍可能有需要人工查看的 warning|
|1|发现 error，例如缺少 frontmatter/字段或失效的普通本地引用|
|2|参数、根目录或读取失败；此次扫描未完整完成|

重复 name、字节内容完全相同、入口超过500个空白分隔词会提示 warning，不自动改写或删除。500词是维护提示，不是格式标准或硬性上限；中文词数尤其不能当 token 数。内容散列相同表示文件相同，不表示两个技能功能等价。

## 范围与边界

只读取指定目录下普通 `SKILL.md`；跳过符号链接和 `.git`、node_modules、虚拟环境、vendor、dist、build。输入根目录可以是你明确选定的链接，工具先解析它；根目录之下的链接不跟随。读取失败会中止并返回2。

引用检查跳过普通反引号/波浪号围栏代码块及反引号行内代码，识别 SKILL.md 中普通行内 Markdown 链接，检查本地目标是否存在。支持URL百分号编码、锚点后的文件路径；不验证锚点、引用式链接或完整Markdown嵌套语法，也不递归检查 reference 文本中的全部引用。未使用尖括号包围的含括号目标只提示人工复核，避免截断后误报缺失。外部网址不联网；超出根目录或经过符号链接的本地目标只提示待审阅，不探查目标。这是轻量检查，不替代完整Markdown解析器。

metadata 检查是简单单行字段的启发式读取：复杂或多行 YAML 给人工复核提示。它不是完整 YAML / Agent Skills 验证器、注入检测器、语义重复检测器或效果评估工具。格式更严谨时使用标准参考工具；内容优化仍需实际任务对照，见 skills-management.md。

## 以后如何持续补能力

1. 从仓库进度、失败记录或重复动作选一个具体缺口，先查是否已有可用工具。
2. 已有工具能解决时复用，明确平台和账号依赖；机械检查写成工具，判断规则才写入 skill。
3. 对真实失败写复现样本；修复后保留回归。低风险文字整理做场景检索和链接核查，不堆砌形式化测试。
4. 每轮记录改变、证据、未验证范围和唯一的下一步；验证后保存 GitHub，后续按记录接续。
5. 没有新的失败或需求时不重复扩写、重复测试。权限、平台或缺少真实数据阻塞的工作明确留待对应环境。

## 仍需对应环境完成

Windows AE 的实际运动/撤销、桌面通知到达、手机通知渠道仍按已有验收记录处理。工具提供了可复用的检查能力，不会替代这些实机步骤，也不会在会话结束后持续运行。
