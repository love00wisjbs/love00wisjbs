# AE 作业策划：《让想法发光》

原创练习提案 v1；没有收到学校/课程题目、评分标准或指定素材，本稿是可改编的自拟作业，不冒充课程要求。状态：策划完成，尚无 AE 工程、录音或成片；审美判断待分镜、动态草稿和真实观众反馈验证。

## 核心表达与发散选择

一句话：一个孤立的想法，通过聚合、变化、连接，成为能影响他人的光。

考虑过三个方向：城市夜景混剪有情绪与摄影质感，但需要可用实拍和授权；角色小故事更有共情，但角色设计与表演工作量大；抽象图形加动态文字容易控制素材和复杂度，适合先练构图、排比和节奏。本稿选择第三种。后续若课程要求实拍、合成或角色动画，再换方向，不硬套。

观众先看懂变化，再感受情绪：开头安静、好奇；中段有秩序地积累；高潮短暂打开；结尾有余韵。验收目标是观众能复述“想法从一个到共同创造”，不是数出用了多少特效。

## 暂定规格与美术系统

- 30秒，1080×1920，30fps，方形像素，900帧；时间表用半开区间，最后一帧899。竖屏便于手机审片；若交横屏，重新构图，不直接拉伸。
- 深蓝黑底 `#101724`，米白 `#F2EEE5` 为信息色，青绿 `#56D6C9` 为主运动色，暖橙 `#F3A56B` 仅作关键点缀。先用纯色形状，不依赖 Glow 制造主体。
- 母题为一个圆点、一条线、一个轮廓。三个主段均保留相似的中心区域与文字基线，让观众识别“同一想法的三种状态”。视觉重心可在中段变化，文字阅读位置保持稳定。
- 中文用一款清晰的无衬线字体及两档字重；候选思源黑体需核对所用版本授权和本机 PostScript 名称。字幕与正文在手机全屏、普通亮度下看清才算通过。
- 首轮将重要信息放在画面中央80%范围，之后按实际发布平台UI遮挡复核。这是工作余量，不是所有平台统一的安全区标准。

## 文案与声音脚本

主文案依次出现：“一个想法”→“让微光相聚”→“让边界展开”→“让彼此相连”→“让想法发光”→片尾署名。

三句排比均以“让”起句，长度接近；画面也用三次“准备→变化→落定→阅读→交接”回应。不是三个一样的转场，而是同一视觉语言下的递进。

可选旁白：
> 一个想法，起初很小。让微光相聚，让边界展开，让彼此相连。于是，想法开始发光。

先做无旁白版本确保叙事可读；需要旁白时再根据实际录音调整时间，不将文字字数当成精确语速。不要在每次运动上叠“嗖”声。暂用120 BPM作节拍标尺（每拍0.5秒），这不是已选定的音乐；最终以授权音乐的段落、音色和实际波形安排声音。

## 分镜与时间轴

所有行首尾连续，时长合计30秒；帧号为包含式可见区间，时间区间右端不包含。

|时间 / 帧|画面与文案|动作、视线与转场|声音与检查点|
|---|---|---|---|
|0–3s / 0–89|大面积留白，一枚青绿圆点；“一个想法”|先静置约0.4s，再极轻的亮度/尺寸变化；文字晚于圆点入场。圆点移向下一段聚合位置|低音或环境底；首帧便有主体，不用3秒黑屏。避免像系统加载图标|
|3–8s / 90–239|“让微光相聚”；少量散点汇入一个有呼吸感的环|先2–3点建立规律，再增加点数；错峰汇入，不让所有点匀速同时到达。末端一个点引出轮廓|一层轻颗粒声；停住后读得完句子，文字不随粒子抖动|
|8–13s / 240–389|“让边界展开”；环变为开放轮廓/几何窗口|保留同一视觉中心，以轮廓扩张表达“变”；遮罩显露新空间。若做Path变形，先统一闭合状态、顶点数和顶点顺序|音色打开，不必增大音量。没有合理拓扑就改用遮罩交接，避免硬拧路径|
|13–18s / 390–539|“让彼此相连”；点分布于简洁网络|前一窗口边缘成为第一条连线；Trim Paths按因果顺序连接，线完成后节点才响应。少量节点足以表达关系|线与节点轻声回应；别画满屏“科技网络”，保留一个最重要的连接|
|18–24s / 540–719|各段母题组成开放的光形；“让想法发光”|18–20s短促聚集，20–21s展开至最大视觉尺度；21–24s减速落定。暖橙只点亮一个关键节点|一次声音峰值，后面留空间。高潮不全屏闪白、不连续闪烁；手机看有冲击而不刺眼|
|24–30s / 720–899|主标题稳定；下方小字“聚合 · 改变 · 连接”和署名|24–25s收束构图，25–29s基本静止供阅读；29–30s可轻淡出。提交版和循环版分别设计|尾音衰减；无音乐也能读懂结论。循环版把最后母题回到首帧，不强求成片版也无缝循环|

## 排比的内部节奏

3–8、8–13、13–18秒各5秒，提供可比较的结构。局部相对时间暂定：0–0.4秒预备；0.4–1.6秒主变化；1.6–2秒落定；2–4秒阅读/微运动；4–5秒交接。实际预览时调整，不把数字当黄金公式。

递进主要来自三件事：聚合段强调“多个变一个”；展开段强调“封闭变开放”；连接段强调“一个影响另一个”。第三次可稍微推迟关键节点亮起，以小幅破格制造期待，但保持文字可读。反复的句式建立秩序，状态变化给重复以意义。

自动化只负责可重复的结构与参数，不替代构图选择。未来若实现JSX，用ES3、matchName、正确ease数组、独立结果文件和串行派发；写入前预检，部分失败不声称已回滚。所有新功能仍需测试与AE实机验收。

建议层结构：每场保留 TYPE、HERO、DETAIL、BG 四组语义；避免一开始几十层随意命名。全局控制器只集中真正需要统一的颜色、线宽和节奏参数；不把所有属性都接表达式，增加排错负担。

## 先做什么与如何判断好看

第一轮只交6张静帧和一条15秒无声动态草稿（聚、变、连），不先铺满30秒。若“看不懂变化”就调整动机与因果；若“看懂但无聊”再调整节奏、对比与惊喜；若“很炫但记不住”就减少同时竞争的动作，强化母题。

验收时分别记录：叙事是否清楚、主要视线是否稳定、动作是否有重量/方向、三段是否既统一又递进、文字是否读得完、高潮是否有前后对比、手机播放是否舒适。测试数字与打分不能代替观众反馈；每条评价附具体秒数和画面证据。

## 发散练习：同一策划的三种气质

- 克制版：点数少、速度变化柔和、停顿多，保留大块空白；用精确的对齐制造品质感。
- 活泼版：点的间距/节奏更有变化，少量预备和回弹；反弹只给有弹性联想的对象，不把文字也做成橡皮球。
- 诗意版：弱化网格，增加不对称和平衡的留白；用光影与时间产生联想，避免靠加噪点和光晕冒充质感。

首轮在同一3–5秒片段中比较两种版本，一次只换一个主要变量。不同时改变构图、配色、速度和音乐，否则无法知道改好在哪里。
