# 动画构思、排比与观赏性

这是可检验的创作启发，不是普遍审美定律；尚未针对本作业完成观众测试。先读任务目的，再选择动作。完整作业示例见 [30秒策划](https://github.com/love00wisjbs/love00wisjbs/blob/main/ae-codex-workbench/docs/creative-assignment.md)。

## 从意义发散，不从特效菜单发散

先写“观众应理解/感受到什么”，再列三个表达方向：叙事（发生了什么）、视觉隐喻（像什么）、节奏（如何被感知）。每个方向写出一个可以画成静帧的提案，检查素材、制作时间和交付平台，再选一个推进。

例如“连接”不只意味着画线：可以是两物相互影响、空隙被填补、孤立声音变和声。若删掉特效仍能看懂关系，表达通常更牢固。不要把所有方向拼在一片里；保留备选和取舍理由即可。

## 动画技巧对照

|技巧|适合表达|实现关注点|常见失误与检验|
|---|---|---|---|
|错峰/跟随|群体、层级、响应|起始偏移、传播方向、主次时间差|每层同曲线同偏移像模板；先建立一个领头对象，问“谁影响谁”|
|预备动作|蓄力、意图、重量|主动作前的小位移或形变|所有对象都反向蹬一下显机械；删除后若更清楚就不需要|
|缓入缓出与落定|材质、情绪、可信度|速度曲线、停留时间、空间路径分别调整|所有关键帧一键Easy Ease；比较静重物、轻物与UI响应的差异|
|重叠/拖尾|惯性、连续性|主体先停、附属后停；避免全体同步|长尾压住下一段文字；单独查看动作结束后的阅读窗口|
|挤压拉伸|弹性、角色态度|围绕接触点，必要时近似保持体积|任意缩放像变瘦变胖；硬金属或正式文字未必适用|
|遮罩/图形匹配|揭示、空间转换|形状、方向、轮廓对应和视线交接|只是擦屏，没有因果；暂停切点看前后是否仍有关联|
|Path变形|身份转变、连续隐喻|顶点顺序/数量、闭合状态、轮廓辨识度|中间打结或突变；逐帧看中间形，不只看首尾|
|Trim Paths|连接、书写、关系建立|路径方向、线端、节点响应顺序|线条满屏无重点；遮掉辅助线后主关系应仍成立|
|视差/镜头运动|空间、探索、尺度|前中后景差异、透视与镜头动机|为了炫技不停推拉；镜头停下后画面是否仍成立|
|停顿/留白|强调、悬念、余韵|动作停止后的阅读和情绪时间|将停顿误当没做完；让停顿有前后动作对比|

这些可迁移的动画原则来自常见动画实践，本表是本包的整理，不声称某个数字配方经过实验或由单一作者首创。

## 排比的四层

1. 文案：相近句式与长度，语义递进。不要只换名词、意义不变。
2. 构图：重复母题、基线或视觉中心；改变一项重点，使观众知道在比较什么。
3. 动作：相同阶段结构，动作意图不同。例如汇入、展开、连接，而非三次同样滑入。
4. 声音：重复音色或节拍建立预期，在关键一次改变或留空。不是每个关键帧都配音效。

重复建立规则，变化提供信息，破格应有目的。“三段”是方便练习的结构，不是作品必须三段的定律。先能说出第三次比第一次增加了什么，再决定要不要强化递进。

## 艺术性与观赏性如何讨论

艺术性不等于更复杂：看形式是否服务主题，选择是否一致，是否有具体可感的情绪或观察。观赏性不等于更快：看视线是否被引导、信息是否可读、节奏是否有变化、观看是否舒适。不同受众和风格会有不同答案。

|维度|观察问题|可以做的小实验|
|---|---|---|
|构图|缩略时第一眼看哪里？边缘是否有无意竞争？|只留黑白块面或模糊看，检查视觉层级|
|色彩|强调色真的强调一件事吗？灰度下还分得清吗？|保留两色试一次；避免同时改速度|
|节奏|哪里在积累，哪里释放，哪里给观众消化？|同段做快/慢两版，保留同一文案和布局|
|材质与质感|粗糙、柔软、明亮的感觉是否有叙事理由？|关掉Glow、噪点、景深后再看主体关系|
|连续性|物体改变方向、消失、出现是否能被理解？|不看声音先判断动作因果，再单独听声音|
|手机体验|文字读得清吗？动作太碎吗？是否有刺眼闪烁？|在真实手机全屏与普通亮度播放，不仅看编辑器放大预览|

审片使用“秒数→观察→影响→一个修改→复看”的记录格式。例如“11.2秒，轮廓和文字同时变化，视线来不及选；将文字提前稳定0.4秒，再比较”。避免只写“更高级”“多点艺术感”。

## 不断改进但不无限重做

每轮选择一条最影响观看的问题，一次只改一个主变量。保留版本、截图/短预览、判断依据和结果；没有观众或预览就标记“假设待验证”。做得好的方法记录成立条件，失败也记录触发条件，不把单次喜欢总结成所有项目都适用的规则。

可用的先后顺序：意义与叙事→构图与文字→时间与路径→声画→细节与输出。上游改变后再检查受影响项；不要把时间都花在尚未确定构图里的微小回弹上。
